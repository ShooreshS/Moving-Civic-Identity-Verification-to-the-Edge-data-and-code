# Claim-to-evidence map

Unless another file is named, field paths below refer to [evidence-summary.json](../evidence/evidence-summary.json). The evidence class describes the work reported by the article. The last column states what a reviewer can check using this package, which contains summaries rather than the underlying experimental datasets.

| Article claim | Public package field | Reported evidence class | Review use and limit |
|---|---|---|---|
| Fifty measured-warm iPhone trials completed | `primaryMobileCohort.completed`, `.attempted`, and timing fields | Mobile benchmark | Compare counts and summary statistics with the article. One iPhone model; trial rows are absent, so statistics cannot be recomputed. |
| All 61 session proofs verified offline | `primaryMobileCohort.sessionProofVerification` | Offline proof replay reported by the article | Inspect accepted, examined, and hash-match counts. Proofs, public inputs, and the verification key are absent; `npm test` does not verify these proofs. The benchmark used a fixed synthetic witness. |
| Proof generation averaged 1,295.8 ms on Samsung S7 edge | `legacyAndroidCohorts[0]` | Retained legacy measurement | Compare the five-run summary with the article. The second array entry is a separate six-run cohort. Trial rows and OS metadata are absent. |
| Registration, proof generation, encrypted-vote submission, and receipt retrieval completed on Samsung S7 edge | `legacyAndroidFunctionalObservation` | Author-confirmed functional observation | Review the stated outcomes and limits. No session export, stage-level timings, build, or OS metadata were retained for this observation. |
| Four registered polls contain verified votes and tallies | `historicalFourPollCohort` | Read-only database census and audit-verifier results | Inspect counts and qualification status. The selected historical cohort's database rows and audit inputs are absent. |
| Four polls completed root and final publication | `historicalFourPollCohort` and [devnet-transactions.json](../evidence/devnet-transactions.json) | Database records and devnet RPC checks | Match four root and four final-result entries to eight public signatures; optionally query public devnet records. Recorded statuses describe the collection-time checks, not a fresh network check by `npm test`. |
| One prospective path connected app, backend, database, receipt, and chain checks | `prospectiveFunctionalRun` | Exact mobile/backend run-ID join and contextual database-time join | Inspect outcomes, timings, and gates for this single observation. Join inputs and its two transaction signatures are absent; the database link uses a unique timestamp within the backend span. |
| Complete request and response measured 4,195 and 560 bytes | `prospectiveFunctionalRun.requestBodyUtf8Bytes` and `.responseBodyUtf8Bytes` | Application-boundary byte counts | Compare values with the [measurement excerpt](../source-snippets/mobile-payload-measurement.js). Bodies are absent, so byte counts cannot be recomputed. One observation; excludes wire framing. |
| Stored and decrypted ballot records contain no account or civil-identity identifier | No public evidence field; manuscript architecture and privacy analysis | Source and schema inspection reported by the article | The relevant record definitions and complete implementation are absent. The measurement excerpts cannot independently establish this claim. Resistance to deliberate transient request correlation was not runtime tested. |
| The vote circuit has the reported dimensions and artifact sizes | `circuitArtifacts` | Reported circuit and artifact metadata | Compare the constraint count, public-input count, and byte sizes with the article. Circuit files, keys, and setup records are absent; the recorded setup status is `internal_one_contributor_release_candidate`. |

The SHA-256 values identify retained private source files. Without those files, reviewers cannot validate their contents, reproduce the reported analyses, or establish that the summaries were derived correctly. Package integrity checks concern the files actually distributed here. See [measurement methods](measurement-methods.md) for the measurement boundaries and optional checks.
